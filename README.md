# AI 소비 패턴 분석 가계부

첫 번째 MVP 버전입니다.

## 실행 방법

1. `index.html`을 더블클릭합니다.
2. 브라우저에서 소비 내역을 입력합니다.
3. `소비 패턴 분석하기`를 누릅니다.

## 구성

- `index.html` : 화면 구조
- `style.css` : 디자인
- `script.js` : 소비 입력/계산/분석 기능
